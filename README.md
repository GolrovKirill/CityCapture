# 🌍 Распределение городов между государствами

Программа на Windows Forms, которая моделирует итеративный захват городов несколькими государствами на основе связного графа дорог. Каждое государство по очереди присоединяет ближайший незанятый город, непосредственно связанный дорогой с его территорией. Результат визуализируется на графе с возможностью пошагового просмотра всей истории захвата.

---

## ✨ Основные возможности

- **Пошаговая визуализация** – просматривайте процесс захвата городов шаг за шагом (кнопки «Назад/Вперёд», трекбар).
- **Автоматическая раскладка графа** – города размещаются по пружинному алгоритму, обеспечивая наглядность.
- **Поддержка пользовательских данных** – загружайте собственные графы из текстовых файлов.
- **Интерактивный граф** – масштабирование колёсиком мыши, панорамирование перетаскиванием, отрисовка петель.
- **Матрица кратчайших расстояний** – вычисляется алгоритмом Флойда-Уоршелла, строки/столбцы подкрашиваются по государствам.
- **Встроенный пример** – тестовый граф из 8 городов и 12 дорог с двумя столицами.

## 🚀 Запуск проекта

### Требования
- Windows 7/10/11
- Установленная среда разработки:
  - **.NET Framework 4.7.2 или новее** (для классического WinForms)  
    *или*
  - **.NET 8.0 / .NET 9.0 SDK** с поддержкой Windows Forms (для современной версии)

### Инструкция по запуску
1. Клонируйте репозиторий или скачайте исходный код.
2. Откройте файл решения `CityCapture.sln` в Visual Studio 2022 или более поздней версии.
3. Убедитесь, что целевая платформа проекта – **Windows** (проект использует Windows Forms).
4. Соберите и запустите проект (`F5` или `dotnet run` для консоли).
